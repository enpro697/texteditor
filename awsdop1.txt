### 【正解選択肢 1】の解説

> **正解 1：** AWS Health から発行される EC2 廃止予定の通知を Amazon EventBridge で受信するルールを構成し、ターゲットとして AWS Systems Manager Automation を指定する。ランブックでは対象インスタンスの停止後に起動を行い、基盤ホストの切り替えを完了させる。

(日乃竜胆) **① AWS Health（旧 AWS Personal Health Dashboard）：**
AWS側のインフラ都合による「計画メンテナンス」や「廃止イベント」の事前予告を発行してくれる専門サービスだ。今回で言えば「`AWS_EC2_INSTANCE_RETIREMENT_SCHEDULED`」というイベントを発行する。
(日乃竜胆) 1. AWS Health (formerly AWS Personal Health Dashboard):
A dedicated service that issues advance notifications for planned maintenance or retirement events originating from AWS infrastructure. In this case, it emits the event `AWS_EC2_INSTANCE_RETIREMENT_SCHEDULED`.

(日乃竜胆) **② Amazon EventBridge：**
AWS内で発生したあらゆる出来事（イベント）をリアルタイムで検知し、あらかじめ設定した処理へ受け渡す「交通整理のハブ」だ。AWS Healthから廃止通知が届いた瞬間に、それをピンポイントで捕捉する。
(日乃竜胆) 2. Amazon EventBridge:
A "traffic control hub" that detects any events inside AWS in real time and routes them to predefined targets. The instant a retirement notice arrives from AWS Health, EventBridge catches it with pinpoint accuracy.
